## Featured Projects
 
### UAA Ecosystem — *Upscaler de Auto-Ajustamento*
> Real-time super-resolution built on **deterministic mathematics**, not neural networks.
 
The UAA ecosystem is my main research project — a hybrid upscaling pipeline inspired by Google's **RAISR** algorithm, adapted for real-time use via HLSL Compute Shaders and DirectX.
 
| Module | Description |
|--------|-------------|
| **UAAI** *(Indirect)* | Spatial, zero-latency post-processing overlay — works on any game via DXGI |
| **UAAD** *(Direct)* | Temporal evolution with motion vectors & depth buffer integration |
| **MNEMOS** | Hash-table-based filter bank (RAISR), O(1) lookup complexity |
| **RAZOR** | Temporal stability module — historical clamping & synthetic motion estimation |
 
`HLSL` `DirectX 12` `C++` `DXGI` `Block Matching` `Compute Shaders` `GLSL` `Vulkan`

### PichalUI - *Dead but important as fuck*
> A **Windows launcher** built in C# / WPF that mimics a console interface — All-in-One experience.
 
- Deep **Steam integration** (friends, chat, achievements, game launching)
- Native controller support (DualSense / XInput)
- *"Pichal Brain"* — smart recommendation engine
- Complex UI animations, custom themes, Christmas Mode
- Hosts UAAI as a post-processing overlay

This project is dead — but it's where **UAAI** was born. That alone makes it worth mentioning.
